# Financial Dashboard Creation

## Project Overview

This project focuses on creating an interactive financial dashboard using Power BI to analyze financial performance and provide meaningful business insights.
The dashboard was developed to transform raw financial data into an interactive reporting solution that helps users understand key performance indicators, revenue and profit trends, financial performance across different categories, and areas requiring management attention.
The project demonstrates the complete data analysis workflow, including data preparation, transformation, data modelling, DAX calculations, KPI development, dashboard design, interactive filtering, analysis, and business recommendations.

## Project Objective

The primary objective of this project is to analyze financial performance and create an interactive Power BI dashboard that supports data-driven business decision-making.

The analysis focuses on:

- Understanding overall financial performance
- Tracking revenue and profit trends
- Comparing financial performance across relevant categories
- Identifying major contributors to revenue and profit
- Identifying areas of strong and weak performance
- Monitoring important financial KPIs
- Providing actionable insights for management
- Presenting the analysis through an interactive Power BI dashboard

## Business Problem

Businesses need a clear and interactive way to monitor financial performance and identify the factors affecting revenue and profitability.

- Which areas generate the highest revenue
- Which areas contribute the most to profit
- How financial performance changes over time
- Which categories or segments require attention
- Where performance is improving or declining
- Which factors have the greatest impact on financial results

This project addresses these challenges by converting the available financial data into an interactive Power BI dashboard.

## Dataset

The project uses a financial dataset containing information required to analyze business and financial performance.

The dataset includes relevant financial and business attributes used for analysis, such as:

## Business Questions

The analysis was designed to answer the following business questions:

1. What is the overall financial performance of the business?

2. How does revenue change over time?

3. How does profit change over time?

4. Which categories or segments contribute the most to revenue?

5. Which categories or segments contribute the most to profit?

6. Which areas show strong financial performance?

7. Which areas show weaker performance?

8. What factors are contributing to changes in revenue and profit?

9. What is the financial impact of the major contributing factors?

10. Which areas should management focus on based on the analysis?

11. What actions can be taken to improve financial performance?

## Data Preparation

The raw data was prepared before performing the analysis.

- Importing the dataset into Power BI
- Reviewing the available columns and data types
- Identifying missing or inconsistent values
- Removing unnecessary columns where applicable
- Correcting data types
- Cleaning and transforming the data
- Standardizing relevant fields
- Creating calculated fields where required
- Preparing the data for analysis and visualization

## Data Modelling

A suitable data model was created in Power BI to support analysis and reporting.

The modelling process included:

- Establishing relationships between relevant tables
- Reviewing relationship cardinality
- Creating appropriate dimensions and fact tables where applicable
- Ensuring the model supports efficient analysis
- Creating a logical structure for financial reporting
- Checking relationships and filter flow

### 1. Business Problem

## Business Recommendations
Based on the findings, management can consider the following actions:

- Focus on the categories or segments contributing the highest value while maintaining their performance.
- Investigate categories or segments showing weaker revenue or profit performance.
- Monitor changes in revenue and profit trends regularly.
- Identify the factors responsible for significant changes in financial performance.
- Review areas with declining profitability and determine the underlying causes.
- Use the dashboard for regular performance monitoring and management reporting.
- Prioritize actions based on the financial impact identified through the analysis.
- Continue monitoring the identified KPIs to evaluate whether business performance improves after corrective actions.

## Limitations
The analysis has certain limitations depending on the available dataset.

- The analysis is dependent on the quality and completeness of the available data.
- The dataset may not contain all factors influencing financial performance.
- Historical data may not fully represent future performance.
- External factors that are not included in the dataset may affect business results.
- The analysis identifies relationships and patterns in the available data but does not necessarily establish causation.
- Recommendations are based on the information available within the dataset.
